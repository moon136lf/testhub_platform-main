10.3 接口一键测试流程（整合补充）
前端→后端：选接口+测试形态+Mock数据→执行
后端：①解析接口文档→②AI生成用例→③审核(可跳过)→④Mock数据构造→⑤执行→⑥报告
协议模拟器：按协议类型(MQTT/HTTP)构造上行/下行报文→校验ACK
报告服务：汇总通过率/失败项/耗时→支持推送
10.4 代码提交触发流程（整合补充）
Git Webhook → 后端触发策略引擎 → 检测接口变更/新增
→ 自动更新接口资产 → 生成接口用例 → 关联执行计划 → 执行 → 报告
