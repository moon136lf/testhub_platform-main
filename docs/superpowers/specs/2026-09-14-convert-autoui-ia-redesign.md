# 用例转脚本 + UI自动化测试 前端信息架构改造设计

- 日期：2026-09-14
- 状态：设计定稿（用户已确认），待写实施计划
- 背景：用户验收反馈——两页面入口交互弱（下拉框选用例）、脚本命名是批次名不是用例名、列表英文枚举未中文化、缺删除、缺翻页；测试集缺详情页与测试记录视图。

## 一、页面1：用例转脚本（ScriptConvert.vue 改造）

**定位：待转清单 + 转换动作。转完即完成使命，脚本管理归脚本库。**

1. **项目选择**：进页自动默认加载第一个项目（下拉仍可切换），不再"未选项目时空白"
2. **用例列表**（替换下拉多选框）：
   - 展示该项目所有**定稿用例**（is_finalized=true）
   - 列：用例名 / 优先级 / 转换状态（automation_status 中文化：pending→未转换, converted→已转换, failed→转换失败）/ 更新时间
   - 排序：更新时间倒序；**翻页栏**（服务端分页，test_cases API 已有 page/page_size/is_finalized 参数）
   - 操作列：**转脚本**（单条触发，SSE 逐步绑定直播在页面内展示）/ **详情**（抽屉：用例步骤表——目标/测试数据/预期结果）/ **删除**（软删用例，二次确认）
3. **转换完成联动**：行状态变"已转换"，行内出现"查看脚本"链接 → **跳转脚本库**对应脚本（不在本页复制展示脚本/代码——消除与脚本库的重复）
4. 转换失败：行内标失败原因，可重试
5. 移除现有"多选用例下拉+批量转换"交互（单条转换为主；批量如保留则列表多选+工具栏按钮，默认不做——YAGNI）

## 二、页面2：UI自动化测试（AutoUITest.vue 改造）

### 脚本库 Tab（默认 Tab）
- 展示项目下**已转脚本**的列表（脚本视角，1用例1脚本）
- **脚本名改用例名**：新转换 `name=用例名`（撞名 -2/-3 后缀，batch_name 降为来源列展示）；存量旧命名脚本列表**显示用例名**（bound_case）
- 列：脚本名（显示用例名）/ 来源批次（batch_name，有则显示）/ 状态 / 上次结果 / 定位来源 / **绑定用例**（修复当前为空的问题——核实 enrich 链路）/ **被 N 个测试集引用** / 更新时间
- **枚举值全部中文化**：状态（never_run→未运行 等）、上次结果（success→成功, fail→失败, blocked→阻塞）、定位来源（element_library→元素库, ai_generated→AI生成, mixed→混合, none_draft→草稿）、转换状态等——前端映射表统一管理
- 操作列：编辑 / 执行 / 报告 / **删除**（删脚本资产，二次确认；引用中的脚本删除时提示被 N 个测试集引用）
- 排序更新时间倒序 + **翻页栏**（脚本列表 API 补分页排序参数）

### 测试集 Tab
- 展示项目下所有测试集列表：名称 / 来源（中文化）/ 用例数 / 最近执行结果 / 更新时间
- 操作列：**详情** / **删除**（删集合，二次确认）

### 测试集详情页（新独立页面 `/auto/ui/set/:id`）
- 顶部信息卡：名称/来源/用例数/创建时间 + **「执行测试集」**按钮
- Tab1 成员用例：本集用例列表（可移除）
- Tab2 测试记录：
  - 每行：触发时间 / 状态（成功/失败/部分失败，中文化）/ 通过率（passed/total 进度条）/ 失败数 / 未执行数（fail-fast 中断时标记，点开展开原因）/ 耗时 / 触发方式 / 操作（查看报告→ReportDetail、再跑一次）
  - 筛选条：全部/成功/有失败
  - 顶部**最近 10 次通过率迷你趋势条**（低成本高感知）
- 暂不做（YAGNI 记录）：定时调度、两次记录 diff、通知推送

## 三、后端配套

1. **转脚本命名**：`build_script_name` 改用例名优先（batch_naming.py；转换链路传 case title 作 base，批次名另存 batch_name 列）
2. **脚本列表 API**：bound_case 修复核实（数据已确认存在，排查前端取值/enrich 空值场景）+ page/page_size/order_by(updated_at desc) + DELETE /scripts/{id}（软删）
3. **用例列表 API**：确认 is_finalized + automation_status + updated_at 排序 + 分页（现有 :302/:237 基础够用，缺则补）
4. **测试集**：DELETE /test-sets/{id}（软删或硬删照现有惯例）；执行记录按 test_set 关联——**ExecutionRecord 现无 test_set_id 列，需加**（执行测试集时写入），记录列表 GET /test-sets/{id}/records（分页+筛选+趋势聚合）
5. **删除联动**：删用例时提示其脚本状态；删脚本不级联删用例

## 四、验收标准

1. 进转脚本页默认第一个项目，定稿用例列表（倒序+翻页）直接可见
2. 单条转脚本 → 页内 SSE 逐步直播 → 完成后行状态"已转换"+"查看脚本"跳脚本库
3. 新转换的脚本名=用例名；脚本库列表显示用例名/绑定用例列不再为空
4. 三列表（转脚本用例/脚本库/测试集）均有删除（二次确认）+ 中文枚举 + 更新时间倒序 + 翻页
5. 测试集详情独立页：执行按钮/成员用例/测试记录（通过率/状态/未执行/查看报告/再跑一次/筛选/趋势）
6. 全量测试不回退 + 前端 build 通过
