### Task 1: ElementHighlight.vue 高亮叠层组件（纯前端）

**Files:**
- Create: `frontend/src/components/element/ElementHighlight.vue`
- Test: 无自动化（视觉组件），vite build + 手动验收

- [ ] Step 1: 实现组件

```
Props:
  screenshotUrl: String        // 代理 URL
  elements: Array              // [{temp_id, position_x, position_y, width, height, element_text, element_type}]
  selectedIds: Array           // 已勾选 temp_id（父组件 v-model 双向）
  hoverId: String              // 外部控制的悬停/闪烁 id（双向联动用）
Emits: update:selectedIds, pick(temp_id), card-hover(temp_id|null)

结构（template）:
<div class="highlight-wrapper" ref="wrapper">
  <img :src="screenshotUrl" @load="onImgLoad" class="highlight-img" />
  <div v-for="el in elements" :key="el.temp_id"
       class="hotspot"
       :class="{ selected: selectedIds.includes(el.temp_id),
                 flashing: hoverId === el.temp_id }"
       :style="hotspotStyle(el)"
       @click="$emit('pick', el.temp_id)"
       @mouseenter="$emit('card-hover', el.temp_id)"
       @mouseleave="$emit('card-hover', null)">
    <span class="hotspot-label">{{ el.element_text || el.temp_id }}</span>
  </div>
</div>

关键实现:
- hotspotStyle(el): 坐标按 截图显示宽/视口宽 比例换算。
  记录 onImgLoad 时 img.naturalWidth（截图像素宽 = 视口宽，devicePixelRatio=1 的 headless 截图）；
  scale = imgEl.clientWidth / imgEl.naturalWidth（若 naturalWidth 不可得用 wrapper 宽）。
  left = el.position_x * scale, top = el.position_y * scale,
  width = el.width * scale, height = el.height * scale（均 px，绝对定位）。
- 三态样式（scoped css，用平台语义色）:
  .hotspot      { position:absolute; border:2px solid #F56C6C; cursor:pointer; }（红框）
  .hotspot:hover{ border-width:3px; }                                  （hover 加粗）
  .hotspot.selected { border-color:#67C23A; background:rgba(103,194,26,.12); }（绿框）
  .hotspot.flashing { animation: flash .6s ease 2; }                     （闪烁：卡→框联动）
  @keyframes flash { 50% { border-color:#67C23A; background:rgba(103,194,26,.3); } }
  .hotspot-label { position:absolute; top:-18px; left:0; font-size:10px; white-space:nowrap; }
- 坐标系注意: bounding_box 是视口坐标，full_page=True 截图若高于视口则 y 轴一致（顶部对齐），x/y 无需偏移；只按显示宽缩放。
```
