##### 3.5.4 业务逻辑
编号
逻辑描述
来源
ELEM-01
抓取时自动识别页面唯一标识（URL path+页面标题）
【deepseek】
ELEM-02
入库时强制确认页面归属：已有页面→归类；新页面→创建
【deepseek】
ELEM-03
入库时自动提取5种定位策略（id/css/xpath/text/role）
【deepseek·L02】
ELEM-04
用户点击截图区域时，系统反查该坐标下最接近的DOM节点（混合点选兜底图标类元素）
【deepseek·L01】
ELEM-05
变更检测对比历史抓取记录，识别新增/删除/变更元素
【联想】
ELEM-06
检测到元素变更时，自动检索引用该元素的脚本列表，标记为"受影响"
【联想】
ELEM-07
用户确认变更后，可一键更新引用脚本中的定位器
【联想】
